## Prompt (English)

```text
Rebuild the attached watch in code and film it. 18 s seamless loop, 60 fps MP4, 1080x1350, three.js only, no 3D files, procedural textures.
→ case is 40 mm, estimate every other part from that
→ compare a still to the image and fix differences, max 3 rounds
→ parts separate along their real install axis, hold as a labelled exploded view, reassemble
→ then the movement runs: gears mesh at correct ratios, balance wheel swings, hands move
→ count parts from the scene graph, never type the number
→ deterministic render(t), Playwright frames, ffmpeg encode
→ check a frame every 0.5 s for glitches before you finish
```
