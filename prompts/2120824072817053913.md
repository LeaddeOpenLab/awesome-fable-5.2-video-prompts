## Prompt (English)

```text
I want you to build an app that takes an image I give you as input and paints it step by step using thick impasto brushstrokes. Break this into two steps:

1. Build yourself a minimal painting tool made up of only the parts needed for this job. Think of it like your own MS Paint or Photoshop brush engine, controlled directly through code, so you don't need to build toolbars or mouse controls for a human user. For real impasto, the brush needs physical depth: raised paint ridges that catch light and cast shadows, bristle marks, and color mixing where strokes overlap.
2. Use the tool from the first step to paint the input image step by step until the oil painting is complete.

- You can use any architecture, tool, or software you want for this.
- After the first step, run a visual self-check before moving on. Render a test canvas with a few overlapping strokes to an image file and view it yourself. Check whether the strokes look like thick, raised oil paint, and whether this tool is enough to paint a full image. If the strokes look like flat 2D shapes, rework the brush engine and test again before starting the second step.

Ask whatever questions you want if anything needs clarification before you start.
```
